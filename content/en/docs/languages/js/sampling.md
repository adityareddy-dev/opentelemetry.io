[Sampling](/docs/concepts/sampling/) is a process that restricts the amount of
traces that are generated by a system. The JavaScript SDK offers several
[head samplers](/docs/concepts/sampling#head-sampling).

## Default behavior

By default, the SDK uses a ParentBasedSampler with an AlwaysOnSampler as its
root. Every new trace is sampled, and a span with a parent follows the parent's
sampling decision. If you do not need to manage data volume, don't bother
setting a sampler.

## TraceIDRatioBasedSampler

When sampling, the most common head sampler to use is the
TraceIdRatioBasedSampler. It deterministically samples a percentage of traces
that you pass in as a parameter.

Use it as the root of a ParentBasedSampler. The ratio then applies only to new
traces, which start with a span that has no parent. A span with an existing
parent, local or from an upstream service, follows the parent's sampling
decision, so child spans are kept or dropped with their parent.

### Environment Variables

You can set up a ParentBasedSampler with a TraceIdRatioBasedSampler root through
environment variables:

```shell
export OTEL_TRACES_SAMPLER="parentbased_traceidratio"
export OTEL_TRACES_SAMPLER_ARG="0.1"
```

This tells the SDK to sample 10% of new traces. Spans with a parent keep the
parent's decision.

### Node.js

You can also configure the samplers in code. Here's an example for Node.js:

{{< tabpane text=true >}} {{% tab TypeScript %}}

```ts
import {
  ParentBasedSampler,
  TraceIdRatioBasedSampler,
} from '@opentelemetry/sdk-trace';

const samplePercentage = 0.1;

const sdk = new NodeSDK({
  // Other SDK configuration parameters go here
  sampler: new ParentBasedSampler({
    root: new TraceIdRatioBasedSampler(samplePercentage),
  }),
});
```

### Browser

You can also configure the samplers in code. Here's an example for browser apps:

import {
  TracerProvider,
  ParentBasedSampler,
  TraceIdRatioBasedSampler,
} from '@opentelemetry/sdk-trace';

const samplePercentage = 0.1;

const tracerProvider = new TracerProvider({
  sampler: new ParentBasedSampler({

  }),

### Using TraceIdRatioBasedSampler alone

To apply the ratio to every span, including spans with a parent, use
TraceIdRatioBasedSampler on its own: pass it as the `sampler`, or set
`OTEL_TRACES_SAMPLER` to `traceidratio`. It then ignores the parent's sampling
decision and decides from the trace ID alone. Upstream services no longer decide
your sampling, but when they sample differently, traces can end up with missing
spans.
